1. Executive Summary & Project Overview

HireHub is an enterprise-grade, full-stack recruitment platform engineered to modernize technology hiring by fusing advanced machine intelligence with intuitive, high-velocity SaaS design. Built from the ground up on modern industry standards, HireHub pairs a reactive React 19 frontend styled with Tailwind CSS v4 and an enterprise Spring Boot 3.3.5 backend backed by MySQL 8.0.

1.1 The Recruitment Dilemma & Problem Statement

Traditional job portals act merely as passive digital bulletin boards, creating massive friction:

  • The Applicant Tracking System (ATS) "Black Hole": Qualified candidates submit resumes blindly, getting rejected by keyword filters without actionable feedback.
  • Recruiter Inundation: Hiring managers receive hundreds of resumes per role, spending hours screening without standardized semantic compatibility rankings.
  • Fragmented Workflows: Hiring teams juggle disjointed platforms for posting roles, reviewing applications, notes, and scheduling interviews.

1.2 The HireHub Solution

HireHub solves these problems through an integrated, three-role ecosystem:

  • Job Seeker Portal: Profile builder, ATS resume scoring, real-time job match checks, automated cover letters, interview coaching, and 5-stage application tracking.
  • Recruiter Console: Full requisition lifecycle, Kanban and Table candidate pipeline, AI applicant scoring, and one-click interview scheduling.
  • Admin Console: Platform-wide telemetry, 1-click user account moderation (suspend/reactivate), and job listing moderation.
  • Fault-Tolerant AI Engine: Cloud Gemini 1.5 Flash inference backed by an automated deterministic heuristic fallback engine.

3. System Architecture & Request Lifecycle

HireHub follows a decoupled 3-Tier Layered Architecture ensuring distinct presentation, business logic, and persistence separation.

Request-Response Lifecycle: Client Browser → React SPA (Axios Interceptor) → Vite Proxy (/api) → Spring Security (JwtAuthenticationFilter) → REST Controller → Service Implementation → AI / JPA Repository → MySQL 8.0 → Response DTO → Client UI Render.

3.1 Layered Backend Structure

  • Controller Layer (`controller`): 9 REST Controllers handling HTTP verbs, parameters, input validation via `@Valid`, and response formatting.
  • Service Layer (`service`, `service.impl`): 9 transactional business services handling entity lifecycles and business constraints.
  • AI Module (`ai`): `GeminiAiService` for cloud inference and `FallbackAiEngine` for deterministic local heuristic scoring.
  • Repository Layer (`repository`): 14 Spring Data interfaces extending `JpaRepository` with custom JPQL queries and pagination.
  • Entity Layer (`entity`): 18 relational domain models with enum bindings and foreign keys.
  • Security Layer (`security`): `JwtTokenProvider`, `JwtAuthenticationFilter`, `CustomUserDetailsService`, and `SecurityConfig`.

5. Comprehensive REST API Reference

Module HTTP Method & Route Access Level Description & Key Payload
Auth POST /api/auth/login Public Authenticates user. Returns JWT token, role, and profile info.
Auth POST /api/auth/register Public Registers new candidate or recruiter account.
Jobs GET /api/jobs Public Multi-filter paginated job search (keyword, location, workMode, salary).
Jobs GET /api/jobs/{id} Public Detailed job description, requirements, benefits, and hiring company.
Jobs POST /api/jobs Recruiter / Admin Creates and publishes new job requisition with skill tags.
Jobs PATCH /api/jobs/{id}/status Recruiter / Admin Toggles requisition visibility (`PUBLISHED`, `PAUSED`, `CLOSED`).
Applications POST /api/applications Job Seeker Applies for a role with resume attachment and custom cover letter.
Applications PATCH /api/applications/{id}/status Recruiter / Admin Advances application status (`SHORTLISTED`, `INTERVIEW`, `SELECTED`, `REJECTED`).
Interviews POST /api/interviews/schedule Recruiter / Admin Schedules interview round with date/time, type, and Google Meet URL.
AI Suite POST /api/ai/resume-analyzer Job Seeker Evaluates resume text; returns ATS score (0-100), detected skills, tips.
AI Suite POST /api/ai/job-match Job Seeker Computes real-time compatibility percentage against job requirements.
AI Suite POST /api/ai/cover-letter Job Seeker Generates tailored cover letters with tone selection.
AI Suite POST /api/ai/interview-prep Job Seeker Generates technical and HR interview questions with sample answers.
Admin GET /api/admin/analytics Admin Aggregates platform telemetry (users, jobs, applications, interviews).
Admin PATCH /api/admin/users/{id}/status Admin Suspends or reactivates user account access.

7.1 Quick Local Setup Commands

# 1. Database Creation
mysql -u root -p -e "CREATE DATABASE hirehub_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 2. Run Backend (Port 8080)
cd backend
mvn clean package -DskipTests
java -jar target/hirehub-backend-1.0.0.jar

# 3. Run Frontend (Port 5173)
cd ../frontend
npm install
npm run dev
